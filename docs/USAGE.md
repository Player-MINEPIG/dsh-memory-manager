# 使用记忆管理

[English](USAGE_en.md) · [README](../README.md) · [安装](INSTALLATION.md)

## 查看资源

从设置打开「记忆管理」查看全局目录，或在已有会话中打开同名页签查看该会话的资源。Skill 目录取决于当前 Agent 的 preset 与工作区；Tavern 资源取决于会话绑定的角色卡、世界书和模板。

可按资源提供方、类型、预设和配置字段筛选。会话面板还支持轮次及存储/读取状态筛选。同一字段内多选满足任意一项，不同字段之间需要同时满足。清空筛选可恢复完整目录。

目录为空时，先检查来源插件是否已启用、Skill 是否对当前会话可用，以及 Tavern 资源是否绑定到当前会话。「查询范围」可查看来源与返回数量；读取失败可使用重新读取入口重试。空会话没有页签时使用全局设置。

## 编辑配置

1. 点击资源的「管理配置」，查看当前值和来源默认值。
2. 选择「跟随来源」以采用该字段的默认值，或打开字段选项设置本地值。
3. 字段页点击「保存并返回」，再在配置页保存管理配置。

未覆盖的字段使用来源默认值；引用预设会覆盖它明确提供的字段。单独选择跟随来源的字段优先采用实时默认值，其他预设字段保持生效。名单、条件树和操作链整体替换，空值可能表示禁用或拒绝，需要按来源说明选择。

「恢复来源默认配置」清除该资源的本地覆盖和预设引用，保存后生效。来源未提供默认规则时，页面会显示原因。正文编辑是独立操作，取决于来源是否允许写入。保存冲突时保留草稿，重新加载配置后合并修改。

需要复用组合时，从「存取预设」创建预设，再在资源配置中引用。修改预设会影响所有引用资源，见[预设文档](PRESETS.md)。

## 查看本轮存取

在会话面板展开一轮对话，分别查看存储和读取状态。无资源活动的轮次也保留。表格中的配置是当前配置，存取记录对应所选轮次。

| 状态 | 含义 |
| --- | --- |
| 读取已触发 | 内容已进入本轮实际 DSH 请求 |
| 存储已触发 | 来源确认本轮写入已提交 |
| 处理中 | 操作仍在执行 |
| 已跳过 | 规则或来源明确跳过，详情中可查看原因 |
| 未记录触发 | 没有相应记录，不能据此判断未使用 |
| 未确认 | 有活动但缺少触发证据，或发生失败、中断 |

正文读取成功、规则命中和预览在详情中单独展示。读取成功可能尚未进入请求；进入请求也不能证明模型采用了内容。历史缺少来源引用时，状态可能保持未记录。

## Skill 的类型与来源

`skill` 是资源类型；`filesystem` 等 provider 是加载渠道。技能可以来自工作区、用户、自定义或随包目录，不要求归属于插件。当前 adapter 显示提供方信息，完整目录来源尚未展示。

Skill 正文为只读。没有稳定身份的虚拟 Skill 可以查看，但不能持久绑定管理配置；接入方可参考[开发者指南](DEVELOPER_GUIDE.md)声明身份。

## 来源保存与请求装配

固定资源的内容随来源变动，存储由来源维护。Tavern 原生 MVU 卡片操作遵循其执行开关和写授权；本插件管理模型读取及助手回复后的更新规则。

要通过管理规则将通用资源加入模型请求，需要在 Prompt Assembler 中选择 `memory-manager.resources`。保存配置不会自动选择请求来源，详见[接入说明](ASSEMBLER.md)。

# 使用记忆管理

[English](USAGE_en.md) · [README](../README.md) · [安装](INSTALLATION.md)

## 打开与查询

全局设置管理所有来源目录与规则；会话页签使用当前会话真实可见范围。Skill 来自 Agent preset/cwd；卡片资源来自来源确认的当前绑定。旧规则、名单和历史触发不建立绑定。全局 Skill 合并 Host 与已加载会话，不主动加载 Agent。

DSH 可能在未发送消息的会话隐藏全部页签，此时使用全局设置。读取失败、会话不存在和没有资源分别显示。查询范围提供来源与数量；GET 超过 30 秒可重试，保存不采用读取超时。

## 轮次与触发

真实持久 `turn/start` 建立标题，无资源活动也保留。展开显示「本轮未记录资源活动」；当前目录和配置仍可展示，不代表资源在过去已存在或被使用。筛选移除全部行也保留标题。缺失轮次不按数字补齐。

读取已触发要求内容进入本轮实际请求；存储已触发要求来源确认本轮写入提交，两列独立。正文读成功、规则求值、许可、开始执行和预览均不足以确认读取触发，详情分别记录。进入请求不证明送达或模型采用。

未记录触发不能证明未使用；未确认表示活动缺少触发证据或发生失败/中断。有界 journal 与核验的历史引用共同提供证据，缺引用不使用当前预览推断。人类输入、任务上下文或系统发起有明确记录时才显示，未知标签隐藏。

## 编辑配置

配置页三栏比较当前值、跟随来源和来源默认。无覆盖字段取来源默认，字段选项页可以选择跟随来源或本地值。来源不提供默认接口时报告原因，不虚构规则。

来源默认 → 本地 → 引用预设合成后，明确跟随字段取实时来源默认。名单、条件树和操作链按字段整体替换，显式空值有意义。恢复默认只改当前资源草稿的覆盖与预设引用，保存后才生效；未知安全扩展保留，身份字段只读。

选项支持搜索、条件树、参数与操作链。「保存并返回」只更新页面草稿，最终保存重新校验来源能力、revision 与磁盘内容，冲突保留草稿。正文使用独立来源权限与 CAS。预设维护见[预设文档](PRESETS.md)。

## Skill 类型与来源

Skill 来自 DSH 技能注册表，不按名称或正文猜测。`skill` 是类型，`filesystem` 等 provider 是加载渠道。工作区 `.dsh/skills`、`.agents/skills`、用户、自定义或随包目录才是具体出处，不要求归属插件。当前元数据只保留 provider，完整目录来源尚未显示。

文件身份由提供方、路径与名称形成；虚拟 Skill 可声明稳定身份，无声明者只可查看、不持久绑定配置。正文只读，目录可见不证明调用，读成功不证明请求进入；标准/native 工具与显式指令均区分这些事实。

## 来源执行与卸载

随固定资源变动是来源维护的存储，不要求 Manager 写入。MVU 原生卡片操作使用 Tavern 绑定、执行开关、授权、schema 与 CAS；Manager 只观察，不授予卡片权限。

预览不生成请求进入回执。通用 assembler 装配需要显式选择来源与宿主能力。移除 Manager 保留规则、来源数据与 DSH 历史；兼容来源为后续操作恢复默认，重装重新采用保留规则。

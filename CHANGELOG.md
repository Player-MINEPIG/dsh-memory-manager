# Changelog / 版本记录

## v1.0.0

### 中文

- 原生全局设置与会话页签统一资源目录、能力、校验和 CAS 保存；正文、权限与 DSH 历史继续由权威来源维护。
- 配置按当前值、跟随来源、来源默认值三栏展示；逐字段跟随实时默认，保留其他预设字段，支持来源维护的固定资源存储。
- 按真实轮次分别显示存储/读取触发，保留空轮次和筛选后无资源的轮次。
- 读取触发要求实际请求进入证据，存储触发要求来源提交回执；读取成功、规则求值、预览、跳过与失败保持独立。
- 支持会话 preset Skill 目录、原生 Skill 工具及显式指令观察；可选世界书、MVU、模板使用公开来源与核验历史引用恢复本轮证据。
- 存取预设提供编辑、整批校验导入、导出；公开 adapter、condition、operation 与来源决策接口。卸载撤销兼容委托，保留用户数据。
- 提供中英文安装、使用、接口、接入、架构与验证文档。包版本不改变协议 1、配置 schema 1 或预设格式 1。

### English

- Native Settings and conversation views unify discovery, capabilities, validation and CAS saves while sources retain bodies, permissions and DSH history authority.
- Three configuration columns show current value, follow source and source default. Field-level following retains other preset fields and supports source-maintained fixed-resource persistence.
- Independent storage/retrieval triggers follow actual turns and preserve empty/filtered-empty headings.
- Retrieval requires actual request inclusion; storage requires source commit receipts. Read success, evaluation, previews, skips and failures remain separate evidence.
- Session-preset Skill catalogs, native tools and explicit invocations are observed. Optional world-books, MVU and templates restore per-turn evidence through public sources and verified historical references.
- Editable presets support atomic validation/import and export. Public adapter, condition, operation and source decision interfaces preserve user data and revoke compatible delegation on removal.
- Bilingual installation, usage, API, integration, architecture and validation documents describe the version. Protocol 1, configuration schema 1 and preset format 1 remain unchanged.
